# scroll-and-screenshots

[English](README.md) | 简体中文

一个 Chrome 插件：从网页顶部开始逐屏向下滚动，将内容保存为按顺序排列、互不重叠的 PNG 截图。

**当前版本：1.0.6。** 插件在 Chrome 中显示为「**ScrollShot · 连续滚动截图**」，项目目录及仓库名保留 `scroll-and-screenshots`。插件界面默认英文；点击弹窗右上角的「**中文**」切换为简体中文，点击「**English**」切回英文。语言选择会记忆，重新打开 Chrome 后仍保留。

## 功能

- 一键从顶部开始，截取支持的网页直到底部。
- 逐张保存 PNG；触底时裁去已截取的重叠内容。
- 一键切换英文和简体中文，截图进行中也可切换。
- 每次任务使用独立的网页标题目录，重名时追加递增序号；图片每次从 `0001.png` 开始。
- 当整页不滚动时，自动识别较大的主体滚动面板，只截取该面板。
- 临时隐藏小型固定悬浮元素，让粘性元素随正文滚动，并暂停 CSS 动画与过渡。
- 显示已保存张数，支持手动停止；关闭弹窗后任务仍可继续。
- 在本地处理和保存，无需账号、API 密钥、后端服务或统计服务。

## 使用要求

- 插件清单要求 Chrome 116 或更新版本。浏览器测试使用过 Chrome for Testing 151；未逐一验证所有 Chrome 版本或其他 Chromium 浏览器。
- 支持的 HTTP/HTTPS 网页；本地 HTML 需要为插件开启文件网址访问权限。

**安装和日常使用不需要 Node.js 或 Python。**

## 安装

### 从源码安装

1. 将本仓库下载或克隆到本地。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开「**开发者模式**」。
4. 点击「**加载已解压的扩展程序**」，选择仓库内包含 `manifest.json` 的 `extension` 目录，不要选择仓库根目录。
5. 在 Chrome 扩展程序菜单中，将「**ScrollShot · 连续滚动截图**」固定到工具栏。

无需构建。安装后请保留 Chrome 已加载的插件目录。

### 从 ZIP 安装包安装

1. 解压本项目生成的 `scroll-and-screenshots-v1.0.6.zip`。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的 `scroll-and-screenshots` 目录。

不能把 ZIP 直接拖到普通网页中安装，需要先解压，再加载对应目录。

### 更新

用新版文件覆盖 Chrome 已加载的插件目录，然后在 `chrome://extensions` 点击该插件的「**刷新**」按钮。重新截图前刷新目标网页。刷新同一插件会保留设置与目录记录；卸载插件会删除其本地存储数据。

## 使用

1. 打开目标网页，等待正文加载完成。
2. 点击插件图标。默认英文，点击右上角「**中文**」可切换；选择滚动等待时间和最多截图张数，再点击 **Start capture / 开始截图**。
3. 保持目标标签页选中；截图期间不要手动滚动、调整窗口、缩放、刷新或最小化目标窗口。
4. 可以关闭弹窗；重新点击图标可查看进度，或点击**Stop capture / 停止截图**。
5. 完成后点击**Show in folder / 在文件夹中显示图片**，或打开 Chrome 设置的下载目录。

| 控件 | 选项与行为 |
|---|---|
| Scroll wait / 滚动后等待 | 默认 0.8 秒；加载较慢时可选 1.5、3 或 5 秒。图片、字体和触底检查可能额外等待。 |
| Image limit / 最多截图张数 | 默认 1000，可设为 1–5000。达到上限停止，保留已保存图片。 |
| 已保存张数 | 只有 Chrome 确认图片下载完成后才增加。 |

切换语言会立即更新界面控件及插件自带的状态提示，不会重启截图任务。网页标题与输出目录名保留原内容；Chrome 返回的技术错误详情可能保留原语言。

任务完成、手动停止或出错后，插件会尽可能恢复原来的滚动位置和临时样式。切换目标标签页、跳转、调整窗口、缩放或最小化可能使任务停止；单纯的窗口焦点变化不会停止任务。

## 保存位置与命名

图片保存在 **Chrome 设置的下载目录** 下，而不是由插件任意选择的磁盘路径：

```text
Chrome 下载目录/
├── 示例网页/
│   ├── 0001.png
│   ├── 0002.png
│   └── 0003.png
├── 示例网页 (1)/
│   ├── 0001.png
│   └── 0002.png
└── 示例网页 (2)/
    └── 0001.png
```

- 每次截图任务使用独立目录，图片始终从 `0001.png` 重新编号。
- 目录名取自网页标题；非法路径字符会替换，隐藏格式字符会移除，过长标题会截短。清理后为空时使用「未命名网页」。
- 目录后缀在已知最大序号上递增，不回填空号。未保存图片就失败的任务也可能占用一个序号。
- 重名判断结合插件保存的目录记录与 Chrome 下载历史；仅清除下载历史不会删除插件的目录记录。
- 下载接口无法枚举任意目录。手工创建且不在两类记录中的目录无法识别；意外遇到同名图片时，Chrome 会给文件名加后缀，避免覆盖。

图片保留捕获时的像素密度，最后一张可能更矮。输出为**多张独立图片，不会拼接成长图**。只截取可见内容宽度，不包含横向溢出内容；内部面板模式不包含面板外侧栏和工具栏。

## 支持范围与限制

插件最适合内容稳定、使用正常文档滚动的网页。内部面板需要完整位于窗口内，宽度至少占窗口一半、高度至少占 40%；符合条件时选择最大的面板。

已知限制包括：

- Chrome 内部页面、Chrome 扩展商店、内置 PDF 阅读器，以及不允许注入脚本的页面。
- 跨域 iframe 或 Shadow DOM 内的滚动区域、多个竞争面板、经过变换或被遮挡的内容。
- 虚拟列表、截图开始后持续重排的内容、实时变化的画布或视频。这些页面可能出现遗漏或前后不一致。
- 无限滚动没有确定终点。触底检查期间没有新内容、达到上限或手动停止时会结束；加载时间超过等待周期的内容可能未被截取。
- 固定悬浮元素会临时隐藏，可能不会出现在图片中；粘性元素和动画会临时调整，页面外观可能与平时不同。

停止或出错不会删除已保存的图片。

## 权限与隐私

| 权限 | 用途 |
|---|---|
| `activeTab` | 用户打开插件时临时访问目标标签页，包括捕获其可见区域。 |
| `scripting` | 滚动页面、读取尺寸、临时调整样式。 |
| `downloads` | 保存 PNG、确认下载完成、查询下载记录以避让目录重名，以及在文件夹中显示图片。 |
| `storage` | 保存界面语言、截图设置、已分配目录名及当前任务进度。 |

插件不申请所有网站的常驻访问权限，不上传截图或网页内容，不使用统计服务或外部截图服务。图片由 Chrome 保存，设置与目录记录保存在插件本地存储中。滚动触发懒加载时，网页本身仍可能发起正常网络请求。

## 常见问题

| 问题 | 排查方法 |
|---|---|
| 尚未保存图片就停止 | 查看插件状态文字；保持目标标签页选中、窗口未最小化。刚更新插件时，刷新插件与网页后重试。 |
| `Invalid filename` | 使用已修复隐藏标题字符问题的当前版本；如仍出现，反馈状态文字和可公开的示例页面。 |
| 无法截取本地 HTML | 在插件详情页开启「允许访问文件网址」。 |
| 图片或下方内容缺失 | 等待页面稳定，改用 3 或 5 秒等待；检查是否使用虚拟列表或不支持的滚动区域。 |
| 保存位置异常或反复询问保存路径 | 检查 Chrome 下载设置与其他下载管理插件；本插件不修改全局下载设置。 |

## 开发

以下命令用于**源码仓库**，不适用于解压后的安装包。开发建议使用 Node.js 20+，打包需要 Python 3。

核心与翻译测试使用 Node.js 内置测试器，无需安装第三方依赖：

```sh
npm test
```

运行浏览器测试或重新导出图标时，安装可选开发依赖：

```sh
npm install --no-save playwright pngjs sharp
npx playwright install chromium
npm run test:e2e
```

浏览器测试使用独立配置，将结果写入 `test-output/`。`CHROMIUM_PATH` 可指定浏览器程序；`TEST_DPR`、`TEST_FILTER`、`TEST_RUN_LABEL` 分别控制像素比例、场景筛选和结果命名。测试浏览器需支持脚本使用的扩展调试命令，插件的最低 Chrome 版本不等于测试工具的最低版本。

```sh
npm run icons     # 从 SVG 源文件重新导出 PNG 图标
npm run package   # 在 dist/ 中生成安装包，需要 Python 3
```

```text
extension/   Chrome 插件文件，安装时加载此目录
assets/      可编辑图标源文件与预览
scripts/     图标导出和 ZIP 打包脚本
tests/      核心、翻译与浏览器测试
```
